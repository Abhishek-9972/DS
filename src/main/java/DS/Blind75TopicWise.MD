## Recommended Study Order
1. **Arrays and Hashing** — Two Sum, Contains Duplicate, Missing Number, Group Anagrams, Longest Consecutive Sequence.
2. **Two Pointers and Sliding Window** — Container With Most Water, Three Sum, Longest Substring, Character Replacement, Minimum Window Substring.
3. **Binary Search and Intervals** — Rotated arrays, Meeting Rooms, Merge/Insert Intervals.
4. **Linked Lists and Stack** — Reverse, cycle detection, reorder list, Valid Parentheses.
5. **Trees and BST** — Traversal, validation, LCA, serialization, maximum path sum.
6. **Heap, Trie, and Backtracking** — Top K, Median Stream, Trie, Combination Sum, Word Search.
7. **Graphs and Matrix Traversal** — Number of Islands, Pacific Atlantic, Word Search II.
8. **Dynamic Programming** — Climbing Stairs, House Robber I/II, Coin Change, Word Break, LIS, LCS.
9. **Bit Manipulation** — Reverse Bits, Number of 1 Bits.

> **Note:** File paths are relative to the project root. Some questions appear under multiple topics when they use more than one major technique.
